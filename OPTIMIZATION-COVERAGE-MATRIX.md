# Optimization Coverage Matrix

## Purpose

Track that every tweakbyjie optimization item has a corresponding explanation in youshouldknow.

## Mapping Rules

Each optimization item should have:

- Optimization name
- Related Windows mechanism
- Reason for modification
- Suitable scenarios
- Possible impact
- Recovery method
